## 🚀 Projetos em destaque

### 💼 [CommitJobs](https://github.com/mateusathos/CommitJobs)

Agregador de vagas de desenvolvimento de software que coleta oportunidades de múltiplas fontes, normaliza e classifica os dados, remove duplicidades e disponibiliza as vagas por uma interface web e uma API REST.

**Destaques:** coleta incremental, processamento paralelo, classificação heurística, PostgreSQL, Flask e deploy em produção.

🔗 [Acessar aplicação](https://commitjobs.onrender.com/)

---

### ₿ [Crypto Portfolio Manager](https://github.com/mateusathos/crypto-wallet-manager)

Aplicação full stack para gerenciamento de portfólios de criptomoedas, com autenticação, transações, cálculo de performance e atualização de preços utilizando a API da CoinGecko.

O backend também fornece uma API utilizada por uma versão mobile desenvolvida em Flutter.

**Destaques:** Flask, SQLAlchemy, Turso/libSQL, API REST, Flutter, integração com API externa e deploy serverless.

🔗 [Acessar aplicação](https://athos-crypto-wallet-manager.vercel.app/) · [App Flutter](https://github.com/mateusathos/app-crypto-wallet-manager)
